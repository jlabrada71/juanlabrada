# What UI Design frameworks are available?

[Material Design](https://material.io/design)

[Bootstrap](https://getbootstrap.com/)  Well,, no need to mention this one, the best known.

[Bulma](https://bulma.io/): The modern CSS framework that just works.

[Semantic UI](https://semantic-ui.com/): the css class names are way better and simpler than Boostrap and Material Design with the same flexibility.

[Carbon Design System](https://www.carbondesignsystem.com/developing/vue-tutorial/step-1): A design language create by IBM with support for different Front End frameworks like vue and react


[Sprout social](https://seeds.sproutsocial.com/writing/goals-and-principles#inspire-trust): Although it doesn't provide resources for design it does provide helpful design guidelines.


[Ant Design System](https://ant.design/):  Well known design system, most resources available for React. It shines in the graph visualization design.


[Tailwindcss](https://tailwindcss.com/): Can not forget to mention this framework that is atomic in philosophy, different of all other, Tailwindcss provides you with the most basic design elements, instead of components which provides you with flexibility to design your components as you wish.

[Braid Design System](https://seek-oss.github.io/braid-design-system/)  : best known for using the stack concept for spacing.
